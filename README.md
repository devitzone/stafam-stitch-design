# STAFAM · Google Stitch Design References

Dieses **öffentliche Repository** ist ausschließlich für Google Stitch bestimmt. Es enthält freigegebene Markenregeln und Vorgaben für neue Screen-Designs, **keinen produktiven Quellcode**.

## Google Stitch starten
Im Dialog **Start with your design**:
1. Unter **Public GitHub repository** `https://github.com/devitzone/stafam-stitch-design` eintragen.
2. Wenn möglich `DESIGN.md` aus der Repository-Wurzel als Designvorgabe verwenden.
3. `STITCH-INITIAL-PROMPT.md` in das Feld **Additional instructions** kopieren.
4. Für visuelle 1:1-Treue zusätzlich die früher ausdrücklich freigegebenen Original-Screenshots in Stitch hochladen. Ein GitHub-Link allein garantiert nicht, dass Stitch Screenshots aus HTML oder Repo-Dateien korrekt übernimmt.
5. Zunächst **nur** das Master-Komponentenboard für Desktop und Mobile generieren; keine weiteren Seitenscreens, bevor die Navigation und das Logo kontrolliert wurden.

## Verbindlichkeit
- **[BESCHLOSSEN]** Farben, Schrift, Navigationsstruktur und das Original-Logo.
- **[VISUELL FREIGEGEBEN]** Auth-V4: Login/Registrierung/Kennwort vergessen, Desktop- und Mobile-Navigation.
- **[OFFEN]** Gestaltung weiterer Bereiche wie Webinare, Kongresse, Dokumente und Mediathek.
- **[NICHT ÜBERNEHMEN]** Abgelehnte Wave-1-Screenentwürfe, alte Stitch-Navigation oder generierte Ersatzlogos.

## Grenzen
Nur öffentliche Website und Digitale Services. **STAFAM Manage ausgeschlossen.** Kein Backend, keine Auth-Zugangsdaten, keine realen Teilnehmerinformationen, keine privaten GitHub-Repos im öffentlichen Export.

Interne Design-Arbeitsquelle: privates Repo `devitzone/stafam-design-system` (keine direkte öffentliche Weitergabe).

Siehe `DESIGN.md`, `STITCH-INITIAL-PROMPT.md`, `SCREEN-CATALOG.md` und `tokens/brand.json`.
